01 / La investigación

Una huerta es mucho
más que lo que crece.

En una institución educativa de Neiva, estudiantes y docentes construyen dos prototipos de huerta como complemento a los procesos formativos: uno vertical y otro convencional. La realidad aumentada acerca sus diseños al aula.

El proyecto combina actividades de siembra, elaboración de compostaje, exploración de sensores y experiencias prácticas de aprendizaje.

05 / Tecnología y monitoreo

Sensores y código
al servicio de la tierra.

Electrónica básica y programación
para observar el ecosistema de la huerta.

Con Arduino, las y los estudiantes pueden leer datos del suelo y del ambiente, reconocer cambios en el microclima de Neiva y tomar decisiones de cuidado con evidencias, no con suposiciones.

01 · SUELO ◉

Humedad del suelo

El higrómetro permite observar la humedad del sustrato en tiempo real para orientar el riego y evitar desperdiciar agua.

02 · AMBIENTE ⌁

Temperatura y humedad ambiental

Un sensor DHT11 o DHT22 registra el microclima de la huerta en Neiva y ayuda a conversar sobre las condiciones de la lechuga crespa y el orégano.

03 · CÓDIGO ↗

Arduino y programación

La placa ejecuta instrucciones para leer datos, activar alertas visuales con LEDs o una pantalla y explorar automatizaciones sencillas.

LECTURA DE HUMEDAD · ARDUINO
const int sensorSuelo = A0;  // Pin analógico del higrómetro
const int ledAlerta = 13;    // LED integrado en la placa

void setup() {
  Serial.begin(9600);        // Abre el monitor serial
  pinMode(ledAlerta, OUTPUT);
}

void loop() {
  int lectura = analogRead(sensorSuelo);
  Serial.print("Lectura del suelo: ");
  Serial.println(lectura);

  // El umbral se calibra observando el sensor y el sustrato.
  digitalWrite(ledAlerta, lectura > 600 ? HIGH : LOW);
  delay(1000);               // Espera antes de la siguiente lectura
}

Ejemplo didáctico: las lecturas dependen del sensor y requieren calibración. El LED indica cuándo revisar el sustrato; no sustituye la observación de las plantas.
